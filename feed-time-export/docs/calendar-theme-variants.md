# Палитры Мур-календаря

Переключатель тем — кастомный тумблер/дропдаун в шапке (тот же паттерн, что у месяца и года). Значение пишется в `data-theme` на `<html>` и в `localStorage` (`mur-calendar-theme`).

Светлые пастели разной гаммы: роза / ягода / мята / лаванда / лагуна. Старые id (`powder-burgundy`, `peach-mauve`, `rose-zephyr`, `latte-cherry`) мигрируют на ближайшие сохранённые темы.

**Список тем без изменений** (5 id ниже). Брендинг шапки обновлён отдельно: заголовок — Google Font **Caveat** (мягкий «околокурсив» с кириллицей), тело — **Quicksand**; логотип — inline SVG «котёнок + миска», цвета из `--paw-*` / акцента темы.

## Как переключать в коде

```html
<html data-theme="cream-rose">
```

Допустимые значения: `cream-rose` · `blush-berry` · `mint-garden` · `lavender-mist` · `sky-lagoon`.

## Z-index и позиция дропдаунов

Списки месяца / года / палитры при открытии переносятся в `document.body` с `position: fixed` (`z-index: 10000`) — портал, чтобы не клипаться stacking-context шапки. Координаты: `trigger.getBoundingClientRect()` → `left`/`top`/`width` строго под триггером; `right`/`bottom`/`inset` сбрасываются (без растягивания `left:0; right:0`); ширина = ширина триггера (палитра ≥ 220px); меню прижимается к краям вьюпорта и при нехватке места снизу открывается вверх. Анимация меню — только opacity (без `transform`, чтобы fixed не «уезжал»). У `.hero` — `z-index: 40`, `overflow: visible`; у `#calendar` — `z-index: 1`.
